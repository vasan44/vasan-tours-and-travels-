## 🚀 Quick Start

### 1. Import Components
```jsx
import { PageSection, CardGrid, Card, Button } from './Layout';
```

### 2. Build Pages
```jsx
<PageSection title="Title" subtitle="Subtitle">
  <CardGrid columns={3}>
    <Card>
      <h3 className="heading-4">Card Title</h3>
      <p className="body-text">Description</p>
      <Button variant="primary">Action</Button>
    </Card>
  </CardGrid>
</PageSection>
```

### 3. Use CSS Classes
```jsx
<h2 className="heading-2">Section Title</h2>

<div className="divider"></div>
```

## 💡 Pro Tips

### Use Layout Components
```jsx
// ✅ Good - Uses layout components
<PageSection title="Tours">
  <CardGrid columns={3}>
    <Card>...</Card>
  </CardGrid>
</PageSection>

// ❌ Avoid - Custom styling
<div className="max-w-7xl mx-auto px-4 py-12">
  <div className="grid grid-cols-3 gap-8">
    <div className="bg-white rounded-xl shadow-lg p-6">...</div>
  </div>
</div>
```

### Use CSS Variables
```jsx
// ✅ Good - Uses CSS variables
<button className="btn btn-primary">Click</button>

// ❌ Avoid - Hardcoded colors
<button className="bg-[#8B2248] text-white px-4 py-2 rounded">Click</button>
```

### Use Design System Classes
```jsx
// ✅ Good - Uses design system
<h2 className="heading-2">Title</h2>
<p className="body-text">Description</p>

// ❌ Avoid - Custom styling
<h2 className="text-4xl font-bold text-[#8B2248]">Title</h2>
<p className="text-base text-gray-800">Description</p>
```
