OPTION 1: Use Your Own Google Maps API Key (Recommended)
========================================================

Step 1: Get Your API Key
  1. Go to: https://console.cloud.google.com/apis/credentials
  2. Click "Create Credentials" → "API Key"
  3. Copy the generated key (looks like: AIzaSyXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX)

Step 2: Add Key to .env.local
  1. Open: frontend/.env.local
  2. Find this line:
     VITE_GOOGLE_MAPS_API_KEY=YOUR_GOOGLE_MAPS_API_KEY
  3. Replace with your actual key:
     VITE_GOOGLE_MAPS_API_KEY=AIzaSyXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
  4. Do NOT use quotes around the key

Step 3: Enable Required APIs
  1. Go to: https://console.cloud.google.com/apis/library
  2. Search for and enable these 4 APIs:
     ✓ Maps JavaScript API
     ✓ Places API
     ✓ Geocoding API
     ✓ Directions API

Step 4: Configure API Key Restrictions
  1. Go to: https://console.cloud.google.com/apis/credentials
  2. Click on your API key → Edit
  3. Under "Application restrictions":
     - Select: HTTP referrers (websites)
     - Add these referrers:
       http://localhost:5173/*
       http://127.0.0.1:5173/*
  4. Under "API restrictions":
     - Select: Restrict key
     - Choose the 4 APIs listed above
  5. Click "Save"

Step 5: Enable Billing
  1. Go to: https://console.cloud.google.com/billing
  2. Enable billing for your project
  3. Note: Google Maps requires billing, but you get $200/month free credit

Step 6: Restart Dev Server
  1. Stop the current server (Ctrl+C)
  2. Run: npm run dev
  3. Open browser and check console (F12)

🔍 TROUBLESHOOTING
==================

If you see "InvalidKeyMapError":
  → Check API key is correct (no spaces)
  → Verify all 4 APIs are enabled
  → Check HTTP referrers include localhost:5173
  → Wait 5 minutes after creating key
  → Enable billing in Google Cloud Console

If autocomplete not showing:
  → Verify Places API is enabled
  → Check browser console for errors
  → Ensure server was restarted after adding .env.local
  → Clear browser cache (Ctrl+Shift+Delete)

If distance not calculating:
  → Verify Directions API is enabled
  → Check both locations are filled
  → Look for errors in browser console
