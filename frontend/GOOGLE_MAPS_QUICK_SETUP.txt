# 🗺️ Google Maps API - Quick Reference

## File Created
✅ `frontend/.env.local`

## What to Do Now

### 1. Get API Key (2 min)
```
https://console.cloud.google.com/apis/credentials
→ Create Credentials → API Key
→ Copy the key
```

### 2. Update .env.local (1 min)
```env
VITE_GOOGLE_MAPS_API_KEY=AIzaSyXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
```

### 3. Enable APIs (1 min)
```
https://console.cloud.google.com/apis/library
Enable:
✓ Maps JavaScript API
✓ Places API
✓ Geocoding API
✓ Directions API
```

### 4. Configure Restrictions (1 min)
```
https://console.cloud.google.com/apis/credentials
→ Edit API Key
→ HTTP referrers: http://localhost:5173/*
→ API restrictions: Select all 4 APIs above
→ Save
```

### 5. Enable Billing (1 min)
```
https://console.cloud.google.com/billing
→ Enable billing
(Free: $200/month credit)
```

### 6. Restart Server
```bash
npm run dev
```
