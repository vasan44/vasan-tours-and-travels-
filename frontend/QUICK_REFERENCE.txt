YOUR TODO (5 MINUTES)
====================

1. Get API Key
   https://console.cloud.google.com/apis/credentials
   → Create Credentials → API Key → Copy

2. Update .env.local
   frontend/.env.local
   VITE_GOOGLE_MAPS_API_KEY=YOUR_KEY_HERE

3. Enable APIs
   https://console.cloud.google.com/apis/library
   ✓ Maps JavaScript API
   ✓ Places API
   ✓ Geocoding API
   ✓ Directions API

4. Configure Restrictions
   https://console.cloud.google.com/apis/credentials
   → Edit API Key
   → HTTP referrers: http://localhost:5173/*
   → API restrictions: Select all 4 APIs

5. Enable Billing
   https://console.cloud.google.com/billing
   → Enable billing

6. Restart
   npm run dev
